# Contributing to OctoIM Android

Thank you for your interest in contributing to OctoIM!

## How to Contribute

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feat/your-feature`)
3. **Commit** your changes with clear commit messages
4. **Push** to your fork
5. **Open** a Pull Request against the `develop` branch

## Development Setup

1. Clone the repository
2. Copy `local.properties.example` to `local.properties` and fill in your configuration
3. Open the project in Android Studio
4. Sync Gradle and build

## Code Style

- Follow existing code patterns and naming conventions
- Java: standard Android coding conventions
- Kotlin: official Kotlin code style
- Add Apache 2.0 license headers to new source files

## Reporting Issues

- Use GitHub Issues to report bugs
- Include device info, Android version, and steps to reproduce
- Attach logs or screenshots when possible
